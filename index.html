Nothing leaves

There is no server. Every tool runs as JavaScript in your tab, so tokens, client names and invoice totals are never transmitted anywhere. Turn off your Wi-Fi and it all still works.

Genuinely fast

No framework, no CSS pipeline, no icon font, no analytics. One small stylesheet and a handful of scripts. Pages paint immediately, even on a bad mobile connection.

Yours to keep

Your profile, clients, presets and documents live in this browser's storage. Export the lot to a JSON file whenever you want, and import it on another machine.
